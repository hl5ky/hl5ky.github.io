1. 개요 :
아마추어 무선 교신에 필수적인 약어들을 모스 부호로 청취 연습하는 word trainer 프로그램입니다.
2. 단어 선택 :
묶음 1, 묶음 2, 묶음 3 및 사용자가 직접 입력하여 추가한 단어 풀을 관리할 수 있습니다.
3. 메뉴 구성 :
• 단어 연습: 선택한 특정 단어만 집중적으로 반복 연습합니다.
• 연습 단어 무작위: 지금까지 연습했던 단어들과 사용자 추가 단어 풀에서 랜덤 송신합니다.
• 전체 단어 무작위: 전체 기본 단어와 사용자 추가 단어를 모두 합쳐 랜덤 송신합니다.
